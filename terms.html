Пользовательское соглашение

Это рабочая версия пользовательского соглашения для браузерного чата. Пользователь отвечает за сохранность данных своего аккаунта и обязуется не использовать сервис для незаконной деятельности.

Функции сервиса могут изменяться по мере развития проекта. Сообщения, звонки и другие возможности предоставляются в рамках доступной инфраструктуры сервиса.

Перед публичным запуском проекта этот документ должен быть дополнен юридическими реквизитами владельца сервиса, условиями использования, ограничениями ответственности и процедурой прекращения аккаунта.
